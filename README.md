### [DriveTrack — Driving Institute Management & RFID Attendance](https://drivetrack-53ab7.web.app)

**React.js · Node.js · Firebase · ESP32 · Arduino/C++ · RC522 RFID · MicroSD**

A deployed Progressive Web App for managing a driving institute, connected to an ESP32-based RFID attendance system.

- Built student records, class scheduling, instructor management, attendance tracking, and multi-admin controls.
- Captured RFID card taps using an ESP32 and RC522 reader and synchronized attendance with Firebase.
- Added MicroSD-based offline logging so attendance is retained during network failures and synchronized after connectivity returns.
- Implemented role-based permissions, audit logging, and real-time Firestore updates.

**Engineering focus:** offline-first reliability, IoT-to-cloud integration, real-time synchronization, and administrative access control.
